# D 갈래 — 외부 제약(법령·산업 상한·원가 울타리) 조사 (시작 즉시 B 와 나란히 던진다)

이 파일을 그대로 서브에이전트 프롬프트로 쓴다. `{회사}`·`{평가기준일}` 두 자리만 바꾼다.

**B 갈래(매출스트림 웹조사)와 무엇이 다른가.** B 는 시나리오 **축의 후보**를 모은다 —
「무엇이 값을 움직일 수 있나」다. D 는 **현금흐름의 울타리**를 모은다 — 「법과 산업이
이 회사의 현금흐름에 무엇을 허락하지 않나」다. 같은 웹을 봐도 가져오는 것이 다르다.
B 가 「45X 로 마진이 좋아질 수 있다」를 축 후보로 적으면, D 는 「45X 는 2030 75%·2031 50%·
2032 25%·2033 0 으로 법이 끝을 정해 두었다」를 **제약**으로 적는다.

**먼저 `.claude/갈래/_공통_실행환경.md` 를 읽는다** — 인코딩·인증·속도·캐시·예산 규약이 거기 있다.

**D 의 산출은 어디로 가나.** 원가 범주(`제약.원가[]`)는 **E 비용동인**이 원가 줄 · 인건비 · 투자 노드의 근거로 읽고(도구 판 `동인진단.py` 도
`_raw/외부제약.json` 의 원가 항목을 닿는 노드의 `근거`(근거강도 「명문」)로 붙인다 — 깊이 2 기본 경로에서도 닿는다),
모순 장부 M-07 은 **이 파일의 다섯 블록 가운데 하나라도 비어 있지 않은데 가정에 `제약` 이 없으면** 울린다(업종 낱말 목록이 아니라 이 구조를 읽는다),
세액공제 · 법인세 규칙은 동인 지도의 **법인세** 노드, 보조금 · 부과금처럼 끝이 정해진 돈은 **한시적 현금흐름** 노드로 간다.
D 는 멈춤 도달 계산에 안 든다 — 늦으면 E 는 D 없이 가고 「D 미도착」을 적는다.

---

너는 외부 제약을 조사하는 에이전트다. {회사} 의 현금흐름에 **울타리**를 치는 것들을 웹에서
찾아 `_raw/외부제약.json` 에 쓴다. 평가기준일은 {평가기준일} 이다.

## 절대 규칙
- **재무제표 수치는 받지 않는다.** 매출·이익·자산 금액은 DART/SEC 가 정본이다. 네가 받는 것은
  **법령의 조문 값**(공제액·단계축소율·적격 비율), **산업 통계의 분모**(시장 GWh·TWh·GW, 그
  정의), **규제의 상한**(요금 산정식·총량 규제·인허가 기한)이다.
- 값마다 **출처 URL·문서명·조문 번호·기준일**을 적는다. 법령은 1차자료(법령 원문·관보·IRS
  Notice·EU Regulation 번호)를 우선하고, 2차 매체는 원문을 못 열었을 때만 그 사실과 함께 쓴다.
  **국내 법령 조문의 첫 수단은 `python 스크립트/조문조회.py 조회 「법령명」 조번호 --기준일 YYYY-MM-DD --캐시 _raw`**(2026-10-17 S6-17 — 법제처 DRF, 키는 환경변수 `LAW_OC`
  만 읽고 `_raw/조문_*.json` 에 캐시). 키가 없거나 닿지 않으면 그 사실을 `coverage` 에 적고 웹으로 간다 —
  국가법령정보센터 웹 원문(`www.law.go.kr` 법령 · 조문 페이지 — 로그인 없이 열린다)에서 조문을 찾아 URL · 시행일 · 조 번호를 적는다.
  2차 매체(세무법인 요약 · 기사)만 봤으면 「확인 필요(원문 미열람)」 로 두고 `영구화금지_근거` 를 비우지 않는다. `LAW_OC` 는 `/준비점검` 이 알린다.
- **계약이 끝을 정한 돈(공급 · 라이선스 · 정부 보조 계약의 시한)은 F 갈래 몫이다**(S6-13 — F `계약시한[]`). 여기는 법령 · 규제의 시한만 싣는다.
- **분모를 반드시 적는다.** 「시장 1.2TWh」만 적으면 안 된다 — 등록차량 탑재량인지, 제조사
  출하인지, 명목 생산능력인지. 우리 판매량 가정(4번 시트의 매출 구분 판매량 줄)과 같은 분모여야 상한이 된다.
- 회사가 말한 목표·계획은 제약이 아니다 — 그것은 B 갈래의 `[회사주장]`이다. 여기엔 싣지 않는다.
- 상한: **벽시계 국내 8분 · 미국 10분 + 출처 종류 체크리스트**(2026-10-16 — 종전 「7분 · 4건」에서 고침). 문서 건수 대신
  종류마다 「봤다」 · 「봤고 없었다」 · 「못 봤다」를 `coverage.출처종류` 에 적는다 — 종류 여섯: **법령 원문 · 관보 · 고시 ·
  규제기관 결정문 · 산업 통계 기관 · 회사 공시의 규제 언급**(회사 공시는 「어느 규제를 받는다」는 언급만 — 재무 수치는 안 받는다).
  닿으면 멈추고 어디까지 봤는지 적는다.

## 찾을 것 — 다섯

| 종류 | 무엇 | 가정 JSON 어디로 가나 |
|---|---|---|
| **법령 현금흐름** | 세액공제·보조금·관세·부과금의 **금액 규칙과 종료·축소 일정** (예: 26 USC §45X 셀 $35/kWh·모듈 $10/kWh, 2030~32 단계축소 · IRA PFE/MACR 비율 · EU 2023/1542 단계 요구) | `제약.법령[]` — `적용행`(아래)·`경로`(연도→잔존비율)·`영구화금지: true` |
| **산업 상한** | 우리 물량이 넘을 수 없는 시장 크기와 그 **분모 정의**(IEA·EIA·SNE·KEEI·통계청) | `제약.산업상한[]` — `지표`·`값`·`단위`·`분모정의`·`대조행`(4번 판매량 줄 · 점유율 대조 줄) |
| **규제 가격·요금** | 요금 산정식·연동제 작동 여부·인가 주기(전기·가스·통신·의약품 약가·도시가스) | `제약.규제가격[]` — `기전`·`최근 결정`·`다음 결정 시점`·`대조행`(4번 단가 행) |
| **재무 약정·한도** | 사채 발행 한도(법정 배수)·차입 covenant·배당 제한·환율 헤지 의무 | `제약.재무약정[]` — `한도`·`일몰`·`위반 시 결과`·`닿는 행`(37~47·220) |
| **원가**(2026-10-16) | 비용 · CAPEX 에 울타리를 치는 규칙 — 전기요금(제조 동력비) · 배출권 가격 · 최저임금 · 근로시간 · 환경 설비 의무 투자 · 세법상 상각 한도 | `제약.원가[]` — `닿는_원가줄`(원가줄k · 인건비 · 투자 · 법인세)·`경로`·`영구화금지` |

**`적용행` 의 뜻(v13).** 그 돈이 실리는 **가정 번호 또는 구조 자리**를 적는다 — 한시적 현금흐름이면 `구조.한시적현금흐름` 과
가정 395 · 404 · 413(흐름 1~3 의 금액), 세액공제면 200 · 940 · 942 · 943(`구조.법인세.*`), 원가면 원가 줄 k 의 가정(A-7k1~7k7 ·
가격지수면 98 · 102 · 106). **키 이름 `적용행` 은 코드(검증기 · 모순 장부 · 자체검사 ㉟)가 읽으므로 그대로 둔다** — 뜻만 v13 이다.

**`제약.원가[]` 의 칸** — `{이름, 조문, 규칙, 경로, 닿는_원가줄, 영구화금지, 적용행, 출처, 기준일, 확인상태, 태그}`.
**`영구화금지` 는 필수다**(법령과 같다 — 빠지면 검증 위반). 기한이 정해진 돈(true)이면 끝나는 해를 `경로` 에, 그 돈이 실리는 가정 번호를 `적용행` 에
적는다 — 자체검사 ㉟ · 모순 장부 M-08 이 법령과 같은 방식으로 그 줄의 영구기간 열을 잰다(적용행이 없으면 ㉟ 가 경보).
`닿는_원가줄` 은 `원가줄1`~`원가줄7` · `인건비` · `투자` · `법인세` 중 하나다(동인 지도의 노드 이름과 같다).
`경로` 는 `{연도: 비율 또는 금액}` dict 다 — 요금 인상률 · 배출권 가격 · 최저임금 인상률처럼 해마다 바뀌는 값.
요금 · 임금처럼 끝나지 않는 규칙이면 `영구화금지: false`, 의무 투자처럼 기한이 정해진 돈이면 `true`.
값을 정하는 것은 E 와 본선이다 — 여기서는 규칙 · 조문 · 결정된 경로만 적는다(회사가 말한 절감 계획은 B 의 `원가_구조` 다).
**어느 범주를 볼지는 회사 유형이 정한다** — 여섯을 다 채우려 하지 않는다. 예: 설비 집약 제조는 전기요금 · 배출권 · 환경 설비 의무,
서비스 · 유통 · 외식은 최저임금 · 근로시간, 클라우드 · 데이터센터 운영사는 전기요금, 미국 회사는 주(州) 최저임금 · 연방 세법의 상각 규칙.
유형상 닿지 않는 범주는 `원가_비고` 에 「해당 없음 — 까닭」으로 적는다.

**레터의 반대 쪽 대조 · 경쟁 위치 재료(2026-10-31 · 레터 원고 요건판 3).** 레터 매출 절은 판매량을 수요 쪽에서 정한 평가에 **연도별 공급 상한 대조 표**를,
생산능력으로 정한 평가에 **연도별 수요 대조 표**를 싣는다(`.claude/갈래/L_레터원고.md` 「요건판 3 의 꼴」 — `관측.반대대조`). 그래서 산업 상한은 한 해 값보다
**연도별 `전망`({연도: 숫자})** 을 먼저 찾는다 — 업계 능력 · 증설 일정(공급 상한), 전방 수요 전망(수요). `분모정의` 를 반드시 적는다(정의가 다른 전망은 평균 내지 않고 줄을 나눈다).
경쟁사의 추가 물량을 막거나 여는 **규제 · 철수**(인허가 · 수출통제 · 환경 규제 · 라인 폐쇄 명령 · 보조금 요건)는 `제약` 블록이 아니라 따로 `_raw/경쟁사제약.json` 에 적는다
— `{"평가기준일", "경쟁사_규제": [{"경쟁사", "종류"(규제 · 인허가 · 수출통제 · 철수 · 보조금), "내용", "조문", "출처", "기준일", "공표일", "기준일뒤", "닿는_칸"}]}`.
`경쟁사` 는 B 갈래 `mentioned_peers` 의 `회사` 와 같은 글자, `닿는_칸` 은 `추가물량.규제` 또는 `추가물량.철수`. 경쟁사에 걸리는 규제가 없으면
`{"경쟁사_규제": [], "비고": "해당 없음 — 무엇을 봤나"}`. 이 파일은 현금흐름 배선이 아니라 레터 경쟁 표의 재료라 검증기를 거치지 않는다(손으로 써도 된다).

「해당 없음 — 무엇을 찾아봤는지」를 적는다. 블록 자리에 문장을 넣지 않는다.

## 형식은 강제다 — 받는 쪽은 사람이 아니라 코드다

`경로`·`영구화금지` 는 모순장부 M-08 · 자체검사 ㉟ · 레터 부록 I 가 **코드로** 읽는다. 문장을 넣으면
어느 자리는 참으로, 어느 자리는 거짓으로 읽히고, 어느 자리는 죽는다. 실측(2026-09-13) — 세일즈포스
D 가 `경로` 를 「국내분 즉시공제: 연도 무관 잔존비율 100%(영구)…」라는 문장으로 적어 레터 부록 I 가 죽었고,
펄어비스 D 가 `영구화금지` 를 「미확정 — 일몰 미확인이라 true 로 단정하지 않음」으로 적었다(문자열은 참으로 읽힌다).

- **`경로` 는 반드시 `{연도: 잔존비율}` dict 다.** 연도는 네 자리 문자열 키, 잔존비율은 **0~1 숫자**
  (「75%」가 아니라 `0.75`). **문장을 넣지 않는다.** 설명은 **`경로_비고`** 에 쓴다.
- **경로가 없는 규칙**(상시 행위 규제·세율 같은 영구 규칙·금액 규칙이 없는 표시 의무)은 **`"경로": {}`** 로 두고
  `경로_비고` 에 「금액 경로 없음 — 상시 규칙」처럼 적는다. `{"비고": "…"}`·`{"설명": "…"}` 도 안 된다 — 연도 키가 아니다.
- **`영구화금지` 는 반드시 `true` 또는 `false` 다.** 따옴표 없는 불리언이다. 「미확정」·「true(추정)」 같은 문자열을 쓰지 않는다.
  - 법령·관보에 **끝나는 날이나 단계축소 일정이 있다** → `true`, `경로` 에 그 일정
  - 조문이 **영구 규칙이라고 확인했다**(일몰 조항 없음을 원문으로 봤다) → `false`
  - **확정하지 못했다**(일몰 여부를 원문으로 못 봤다) → **기본값 `true`** 로 두고 **`영구화금지_근거`** 에
    「미확정 — 일몰 조항을 원문으로 확인 못 함(무엇을 봤는지)」을 적는다. 확인 안 된 돈을 영구가치에 싣지 않는 쪽이
    기본이다(시나리오 규칙 「낙관은 관측 안에서 멈춘다」와 같은 비대칭). 값에 안 싣는 제약이면 `반영: false` 와 사유를 함께 적는다
- `영구화금지: true` 이면 `경로` 가 비면 안 되고, **마지막 해의 잔존비율이 0** 이어야 M-08 이 영구 열을 잰다.
  확정 못 해 일정을 모르면 경로에 아는 해까지만 적거나(모르면 `{}`) `영구화금지_근거` 에 모른다고 적는다 —
  근거가 적힌 빈 경로는 검증이 경고로만 낸다.
- `산업상한[].전망` 은 `{연도: 숫자}` dict, `재무약정[].닿는_행` 은 행 번호 list(`["37", "45", "220"]`)다.
- `산업상한[].구분` · `기준`(판매량 · 매출액) · `분모같음` 은 본선이 붓기 전에 적는다 — D 는 `분모정의` 를 반드시 적고 `분모같음` 은 비운다(분모 판정은 본선).
  문장은 `비고` 칸에.

틀린 모양과 고친 모양 —

```json
// 틀림
"경로": "확인 불가 — 요약상 일몰일 기재 없음",   "영구화금지": "미확정 — 일몰 미확인"
"경로": {"비고": "금액 경로 없음 — 상시 행위 규제"}
"경로": {"2030": "75%"}
// 고침
"경로": {}, "경로_비고": "확인 불가 — 요약상 일몰일 기재 없음", "영구화금지": true,
"영구화금지_근거": "미확정 — PwC 요약에 일몰 미기재, 법령 원문 미열람", "반영": false, "미반영사유": "…"
"경로": {}, "경로_비고": "금액 경로 없음 — 상시 행위 규제", "영구화금지": false
"경로": {"2029": 1.0, "2030": 0.75, "2031": 0.5, "2032": 0.25, "2033": 0.0}, "영구화금지": true
```

## JSON 을 손으로 쓰지 않는다 — 작성 도구로 블록마다 넣는다(2026-10-16)

자유 JSON 은 형식이 계속 깨졌다(옛 산출 넷 — 하이닉스 · 펄어비스 · 세일즈포스 · LG에너지솔루션 — 이 전부 검증 rc 1). 블록마다 항목을 넣고,
**넣을 때마다 검증을 통과해야 파일을 쓰는** 작은 도구를 쓴다.

    python 스크립트/외부제약작성.py --새로 --회사 "{회사}" --가정 {가정}      # 두 날짜(평가기준일 · 재무기준일)를 가정에서 — 날짜 둘(2026-10-25)
    python 스크립트/외부제약작성.py --법령 '{"이름": "…", "조문": "…", "규칙": "…", "경로": {"2030": 0.0}, "적용행": "395", "영구화금지": true, "출처": "…", "기준일": "…", "확인상태": "…", "태그": "[공시]"}'
    python 스크립트/외부제약작성.py --원가 '{"이름": "…", "닿는_원가줄": "인건비", "경로": {"2027": 0.05}, "영구화금지": false, …}'
    python 스크립트/외부제약작성.py --해당없음 산업상한 "그 유형에 물리 상한이 없다 — 무엇을 찾아봤는지"
    python 스크립트/외부제약작성.py --상태 완료

위반이 있으면 쓰지 않고 위반 문장을 낸다 — 고쳐 다시 넣는다. `coverage` 같은 머리 칸은 도구가 만든 틀에 이어 적는다.

## 조항은 원문에서 뽑아 인용째 넣는다 (2026-10-21)

**재무약정 · 장기공급계약 · 지급보증 · 우발부채는 대상회사 원문 주석에 있다** — 웹을 찾기 전에 원문 후보부터 본다.

    python 스크립트/조항추출.py 가정_회사.json              # → _raw/조항후보.json (후보 문단 · 절 · 문단 번호 · 원문 인용 · 숫자)
    python 스크립트/조항추출.py --raw _raw                 # 가정을 짓기 전 조사 단계(2026-10-24) — `--대조` 도 같다

후보를 읽고 넣을 항목을 `외부제약작성.py` 로 넣되, 그 항목에 **`원문인용`(원문 문단 글자 그대로 · 1,200자 안) · `원문접수`(접수번호 14자리)** 를 단다.
후보 목록에는 표 이름 줄이나 일반 문단이 섞인다 — 고르는 것은 이 갈래다. 넣은 뒤:

    python 스크립트/조항추출.py 가정_회사.json --대조         # → _raw/조항대조.json · 인용이 원문에 없으면 rc 1

rc 0 이어야 낸다. 재무약정 항목에 `원문인용` 이 없으면 `외부제약검증.py` 가 경고하고 `--대조` 가 경보한다.

## 내기 전에 — 검증을 돌려 0 이어야 한다

`_raw/외부제약.json` 을 쓴 뒤 **반드시** 돌린다(작성 도구를 썼으면 이미 통과한 것이다 — 한 번 더 돌려 보고에 적는다).

    python 스크립트/외부제약검증.py _raw/외부제약.json

**종료코드가 0 이어야 낸다.** 1 이면 찍힌 줄 번호·키를 고치고 다시 돌린다(경고는 남아도 된다 — 보고에 적는다).
검증기는 원가 범주도 잰다(블록 다섯 — `경로` {연도: 숫자} · `영구화금지` 필수 · `닿는_원가줄` 은 원가줄1~7 · 인건비 · 투자 · 법인세 가운데 하나).
검증을 못 돌렸으면 「검증 못 돌림」이라고 보고 첫 줄에 적는다. 돌린 척하지 않는다.
