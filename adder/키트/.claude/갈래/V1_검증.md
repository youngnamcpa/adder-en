## 볼 것 — 순서대로. 하나 끝내면 바로 파일에 쓴다

**1. 검증행 자체 (여섯 시트 전부 — 1 · 3 · 11 · 14 · 15 · 16)** — 「OK」를 그대로 믿지 않는다. `검증.md` 의 다섯 갈래로 나눠 본다.
   - 조건이 실제와 반대인데 OK — **판정 칸이 무는 셀이 라벨이 말하는 그 셀인지** 수식을 따라간다
   - 항진명제 — 수식으로 채운 칸을 같은 수식 값에 대조하거나, 하드코딩한 행 목록과 나머지 행의 합집합이 전체라 **구조상 항상 0** 인 행
   - 상수 문자열·카운터 — 「OK」가 박혀 있거나 「N / N건」처럼 실패할 수 없는 행
   - 아무것도 안 세는 행 — 참조 범위가 비었거나 빗나감
   - 롤업의 사각지대 — 「확인 필요」만 세고 「신호 —」·「해당 없음 —」을 안 세는지, **정확일치인지 와일드카드(`*`)인지** 수식에서 확인.
     사유 칸에 **글자만 있으면** 신호로 강등하는 행은 사유 내용을 안 본다는 것도 적는다
   - 「검사 대상 아님」이라고 스스로 밝힌 상수 칸은 가짜 OK 가 아니다 — 구별해 적는다

**2. 11번 — 브리지 구성**
   - 순차입금 = 총차입금 **합계** − 현금성자산 **합계**. 합계 위 한 줄을 빼고 있지 않은가(기아 회차 결함 — 순현금 회사의 부호가 뒤집혔다)
   - 비영업자산·현금성·총차입금 합계의 SUM 범위가 항목 전부를 덮는가 · 스위치 텍스트 행이 SUM 에 끼어 있으면 무해한지
   - 리스부채 스위치(포함/제외)와 실제 배선이 같은가 · 유동·비유동 둘 다 들어갔는가
   - 법인세 자산·부채가 순차입금·비영업 어디에도 없는가(주당가치 규칙)
   - 우선주·비지배지분·순확정급여부채가 0 이면 **원천이 확인한 0 인지, 빈칸이라 0 인지** — 미입력 검사 대상에 들어 있는가
   - 비영업자산 처분 세효과가 양(+)의 평가증에만 걸리는가
   - **교차 보유 · 관계기업**(S10-14 · S10R1-N5) — 지분 성격 장부(관계기업 · 장기투자자산 · 지분 줄) ÷ (영업가치 + 비영업 장부)가 20% 를 넘는데 장부가 그대로 더해졌으면 시가 · 지분경로 · 지주 할인 가운데 무엇을 골랐는지(⑳ R-165 — 금융상품 성격 비영업은 시가 ≈ 장부로 목록 · 영업가치 ≤ 0 이면 몫 없음)
   - **우선주 갈래**(`구조.가치조정.우선주` — 없음 · 시가차감 · 부채성 · 지분동등)와 98(금액) · 956(보통주 환산 수) · 110(부채성)의 배선이 같은 갈래를 말하는가(주당가치 규칙 · S7-04)
   - **지분경로**(경로 DCF)가 있으면 11번 111 의 배율 칸 = 엔진이 경로로 센 배율인가(⑳ ②-d — 연장 · 되돌리기 사본에서 갈린다 · S8R1-N4)
   - **리스 짝** — 사용권자산이 있는데 리스부채(39 · 47)가 0 이면 막음(⑳ ②-c)

**3. 3번 — WACC 재현** (허용 차 0.01%p)
   - 근거 네 칸(값·출처·기준일·확인상태)이 Rf·ERP·CRP·βU·현금비중·한계세율·D/E·스프레드 행마다 찼는가
   - βL = βU × (1 + (1−t) × D/E) → Ke = Rf + βL × ERP(CRP 는 ERP 안 — 이중가산 없는가) → Kd(세전) = Rf + 스프레드(타인자본비용 입력 규칙의 구조) → 세후 Kd → WACC 를 **손으로 다시 계산**해 캐시값과 대조
   - **Rf 쪽 이중 계상**(S7-01) — Rf 가 국채 수익률 그대로인데 MRP 에 국가위험(CRP · Total ERP)이 들었는가. Rf = 국채 − 같은 판 국가 부도 스프레드(무위험이자율 입력 규칙)인지,
     부도 스프레드 · 성숙 ERP · CRP 가 같은 ctryprem 판 · 같은 국가 행인지 본다. 스프레드 갈래(다모다란 등급 스프레드)면 스프레드 칸에 부도 스프레드가 더해졌는지(타인자본비용 입력 규칙)
   - βU 근거가 C2 산출의 **본값**(`본값.핵심.본값`)인가 — 본값 제외 회사 · 포함 값 · 95% 구간 · 산업 βU 대조(±30% ★)가 근거에 실렸는가(베타 입력 규칙)
   - D/E 의 분모가 시가총액(주식수 × 종가)인가, 산술이 맞는가 · **목표 자본구조**(`WACC.<구간>.DE`)를 썼으면 그 근거와 영구 칸 D/E 가 맞는가(S7-09)
   - **연도별 WACC**(`구조.할인.연도별WACC = 사용`)면 2번 할인표(26~35)의 열별 할인율이 예측 → 영구 WACC 로 걷는가(예측기간 규칙)
   - 타인자본비용 입력 규칙 — **등급이 있으면 합성등급을 쓰지 않는다** · 반기 기준일이면 반기보고서 신용평가 절을 봤는가 · 두 Kd 경로 차이 3%p 초과면 원인이 지목됐는가
   - βU 에 현금보정(베타 입력 규칙 · 유사기업 베타 계산 규칙)이 걸렸는가 · Ke < 세전 Kd 서열 위반이 있으면 그 사실과 사람 판단 흔적

**4. 1번 — 가치 브리지 사슬과 기록 칸**
   - 영업가치 → (+비영업 +현금성 −총차입금 −우선주 −비지배 −순확정급여 ±기타) → 주주가치 → ÷ 주식수 → 주당가치. **고리마다 셀·값을 표로** — 1번 셀 · 1번이 무는 셀 · 값 · 11번/13번 대응
   - 부호가 이중 차감이 아닌가 · 금액단위 ↔ 주당 환산 배율이 맞는가 · 음수면 0 하한 + DCF 값 병기 구조
   - 주식수가 자기주식 차감 유통주식수인가(주당가치 규칙) · 시가총액 ÷ 종가 = 같은 주식수인가
   - 기록 칸(비관·기준·낙관 주당·영업가치·주주가치) — **비관 < 기준 < 낙관**, 적용 시나리오 열이 지금 계산과 같은가, 기록 칸 내부 브리지 차감액이 세 시나리오에서 설계대로인가

## 쓰는 법 — 이것이 끊겨도 남는 방법이다

- 산출물은 **`_raw/검증_V1.md` 한 파일.** 맨 위에 `status: 진행중` · 한 줄 요약 자리를 두고, **절 하나를 끝낼 때마다 이어 쓴다.**
  마지막에 몰아 쓰지 않는다. 끝나면 `status: 완료` 와 건수(확인함 N · 확인 못 함 N · 사람이 볼 것 N)로 머리를 고친다.
- 쓰기 도구가 없는 에이전트(`검증.md` 는 읽기 도구만 준다)로 던졌으면 **절 하나마다 짧게 답을 끊어 보내고**
  본선이 그대로 `_raw/검증_V1.md` 에 이어 붙인다. 쓰기 도구가 있으면 **이 한 파일에만** 쓴다 — 워크북·가정·장부는 절대 안 건드린다.
- 큰 덤프는 **Grep 으로 좁히고 Read 는 offset·limit 으로 자른다.** 통째로 Read 하지 않는다.
- 항목마다 번호를 단다(`K1`·`N1`·`H1`) — 본선이 「반영한 지적」을 번호로 적는다.

## 형식 — 셋으로 가른다

- **확인함** — 셀 좌표와 값, 다시 계산한 식을 함께
- **확인 못 함** — 원인을 넷 중 하나로: 조회 경로 문제 · 항목 부재 · 보고 의무 없음 · 보고 시점 미도래
- **사람이 볼 것** — 무엇을 판단해야 하는지 **한 줄**. 두 값이 갈리면 **고르지 않고** 두 값·두 자리를 적는다

찾은 것을 고치지 않는다. 목록으로만 낸다. 같은 지적을 V2·V3 도 낼 수 있다 — 겹쳐도 된다, 줄이려고 남의 절을 보지 않는다.
