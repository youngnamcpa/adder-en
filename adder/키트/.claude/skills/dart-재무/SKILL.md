> 처음이면 `/준비점검` 부터 — 설치 · 키 · 접속을 한 번에 본다(영문 `/preflight`).

## ⚠ 먼저 — **어느 나라 회사인가**

| 상장 시장 | 창구 | 어떻게 |
|---|---|---|
| **국내(KOSPI·KOSDAQ)** | **DART OpenAPI** | 이 스킬 — 아래 두 줄 |
| **미국(NYSE·NASDAQ)** | **SEC XBRL** | `python 스크립트/sec_fetch.py --ticker PLTR` → `sec_원천.py --기준일 …` · `sec_앵커.py` |

**둘 다 아닌 시장(일본·유럽·중화권)은 이 프로젝트에 창구가 없다.** 그 종목은 **관문에서 「원본 확보 경로 없음」으로 멈춘다** —
웹에서 재무 수치를 옮겨 적지 않는다.

예 `/dart-재무 SK하이닉스 2026-06-30`. 인자가 안 넘어오면 대화로 회사명과 평가기준일을 물어본다.

## 두 줄 — 손으로 고유번호 · 접수번호 · 전체 재무를 부르지 않는다(2026-10-16)

    python 스크립트/dart_fetch.py --찾기 {회사명}                       # 고유번호(종목코드가 있는 줄 — 상장폐지사 주의)
    python 스크립트/dart_fetch.py --회사 {고유번호} --기준일 {평가기준일}  # 개황 · 제출이력 · 전체 재무(연결 · 별도) · 앵커 · 원문
    python 스크립트/dart_원천.py --기준일 {평가기준일} [--해수 3]         # 13번 원천 조립 → _raw/원천_조립.json (실적 회계연도 수 — 기본 2)

첫 줄은 회차에 한 번이다. 둘째 줄이 하는 일과 함정은 도구가 안다 — 그 머리말과 키트 `CLAUDE.md` 「재무제표를 가져올 때」가 정본이다.

- **반기 · 분기 손익의 3개월 함정** — 도구가 누계(`thstrm_add_amount`)를 쓰고, 현금흐름표 순이익 행이 3개월이면 알린다
- **앵커**(매출 · 매출원가 · 판관비 · 영업이익 네 줄) — 부호 전환을 세며 스스로 늘어난다(전부 흑자이고 이익률 최고 ÷ 최저가 2배 미만이면 여섯 해에서 멈춘다 — 흑자 속 사이클이면 앞 국면까지 간다 · `이익률진폭`). 해마다 항등식 · 구조 단절 후보
- **원문** — 기준일 보고서(정정본 우선)와 최신 · 과거 사업보고서를 `_raw/반기` · `_raw/사업YYYY` 에 함께 받는다(주석은 원문에만 있다)
- **결산월** — 기업개황 `acc_mt` 가 12 가 아니면 멈추고 묻는다(`--결산월확인`)
- **실적 회계연도 수**(2026-10-18 S10-16) — 템플릿 `실적연도수 3` 이면 `--해수 3`. 앞의 해는 앵커 사업보고서의 전기 · 전전기 열에서 채운다
- **영업이익 66** — 워크북 항등식(62 − 63 − 65)으로 낸다. API 영업이익이 다르면(기능별 표시) 공시값은 `검산행.66_공시` · `주의` 에(S10-13)
- **소계 대조 · 법인세 부호 · 사용권자산 ↔ 리스부채 짝 · 태그와 계정명 어긋남 · 기타 미배분 후보** — `dart_원천.py` 가 `주의` 로 낸다(모순 장부 M-06)
- **계정명 매핑** — 표준 태그 → 계정명 순. 매핑에 없는 계정은 버리지 않고 `행없는계정` · `기타후보` 로 모인다. 새로 판정한 계정은 작업 폴더의
  `계정매핑_추가분.json` 에 쌓는다(`references/계정명_매핑.md`)

## 산출 — 받는 쪽이 정해져 있다

`_raw/dart_재무_{연결|별도}_{연도}_{보고서코드}.json` · `_raw/dart_앵커시계열.json` · `_raw/dart_기업개황.json` · `_raw/dart_제출이력.json` ·
원문 폴더 → `_raw/원천_조립.json`(13번 원천 · 검산행 · 소계대조 · 앵커 · 주의). 원천 조립은 A2 가 검산하고 가정 JSON 의 `원천` 으로 옮긴다 —
**채팅 표로만 내지 않는다**(사람이 눈으로 옮겨 적게 된다).

## 하지 않는 것

- 못 구한 값을 비슷한 값으로 메우지 않는다. **확인 불가**로 적고 원인을 조회 경로 문제 · 항목 부재 · 보고 의무 없음 · 보고 시점 미도래 중 하나로 분류한다
- 요약 재무제표에 없는 항목을 「없다」고 단정하지 않는다. **주석(원문)을 먼저 확인한다** — 이자비용과 무형자산상각비가 대표적이다
- 도구가 있는 일을 손 절차로 다시 짜지 않는다(`.claude/갈래/_공통_실행환경.md` 「도구를 손으로 대체하지 않는다」)
