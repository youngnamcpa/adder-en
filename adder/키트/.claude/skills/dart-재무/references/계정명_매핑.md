# 계정명 매핑표

**같은 것을 회사마다 다르게 부른다.** 이름 하나로만 찾으면 합계가 0으로 나온다.

## 이자부부채

아래를 **모두** 훑는다. 하나만 찾고 끝내지 않는다.

    차입금 / 단기차입금 / 유동성장기차입금 / 장기차입금 / 유동성장기부채
    사채 / 회사채 / 유동성사채 / 사모사채
    리스부채 / 유동리스부채 / 비유동리스부채
    전환사채 / 신주인수권부사채 / 교환사채
    상환전환우선주 / 상환우선주 (**부채로 분류된 것만**)

**실제로 갈린 예.** 하이닉스는 「차입금」 하나로 묶고, 삼성전자는 단기차입금·유동성장기부채·사채·장기차입금 넷으로 쪼갠다.
그리고 **삼성전자 요약 재무상태표에는 리스부채 계정이 없다.** 「차입금」으로만 찾으면 0이 나온다.

## 이자부부채에 넣지 않는 것

    매입채무 / 미지급금 / 미지급비용 / 예수금 / 선수금
    충당부채 전부 / 이연법인세부채 / 당기법인세부채
    순확정급여부채 (이 모델은 제외로 통일한다)
    파생상품부채 / 통화선도부채
    기타금융부채 (**기본 제외.** 자기자본의 1%를 넘으면 주석에서 이자부 항목만 분리)

## 이름이 비슷한데 자산인 것

    사용권자산 / 리스채권 / 대여금

## 주석까지 들어가야 나오는 것

    이자비용 — 요약에는 「금융비용」 묶음만 있다.
              금융비용에는 외환차손·파생상품평가손실이 섞여 있어 그대로 쓰면 안 된다
    무형자산상각비 — 감가상각비와 따로 잡히는 회사가 있다

## 미국 공시

    네임스페이스가 회계기준마다 다르다. 미국 기업은 `us-gaap`,
    국제회계기준을 쓰는 외국 기업은 `ifrs-full` 이다.
    한쪽만 열고 「자료 없음」으로 결론 내지 않는다.
    표준 태그를 안 쓰는 회사가 있다. 같은 뜻의 다른 이름을 먼저 훑는다
    (`InterestExpense` 가 없으면 `InterestExpenseNonoperating` 을 본다).
